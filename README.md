# Zombie Escape

A 3D third/first-person zombie survival game set on a mountain escape route.

## Features (planned)
- Narrated intro backstory
- Atmospheric main menu with settings and character select
- Male and female protagonists with 3 outfits each
- Zombie combat and survival
- Hidden loot and a dog rescue mission

## Tech
- Godot 4.x
- GDScript

## Status
In development.
